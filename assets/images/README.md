# App Store Buttons Instructie

## Download de afbeeldingen die je hebt geüpload en plaats ze hier:

1. **App Store button** → Sla op als: `app-store.png`
2. **Google Play button** → Sla op als: `google-play.png`

## Stappen:

1. Download de button afbeeldingen van je eerste bericht
2. Plaats ze in deze map: `/assets/images/`
3. Hernoem ze naar:
   - `app-store.png` (Apple App Store button)
   - `google-play.png` (Google Play button)

De website is al geconfigureerd om deze afbeeldingen te gebruiken op de homepage!

## Alternatief: Gebruik SVG placeholders

Als je de afbeeldingen niet direct hebt, kan ik tijdelijke SVG placeholders maken.
