W

WebTool Scraper

Een browserextensie die op elke pagina waarden scrapet, formulieren vult en knoppen drukt — in één flow, per CSV-rij herhaald. Alles lokaal

In het kort

Een extensie bouw je niet met een compiler — het zijn gewone bestanden (HTML/JS/JSON) die je map in de browser laadt. Hieronder: eerst de bestaande map laden (2 minuten), daarna — als je het zelf van nul wilt begrijpen — de minimale opbouw.

1Wat je nodig hebt

  • Een op Chromium gebaseerde browser: Chrome, Edge of Brave.
  • De map extension/ (uitgepakt uit de zip). Geen Node, geen build-stap nodig.

De map bevat:

extension/ ├─ manifest.json verplicht rechten + welke scripts laden ├─ panel.js de hele tool (content-script) ├─ panel.css overlay-stijl op de pagina ├─ background.js service worker (downloads, print, toggle) ├─ icons/ icon16/48/128.png ├─ docs/ deze uitleg + FLOW.md └─ mcp-server/ optioneel: AI-agent-koppeling (Node)

2Laden in de browser

  1. Open chrome://extensions (of edge://extensions).
  2. Zet rechtsboven Ontwikkelaarsmodus aan.
  3. Klik Uitgepakte extensie laden en kies de map extension/.
  4. Er verschijnt een blauw W-icoon in de werkbalk. Zet hem eventueel vast (pin).
Na een wijziging aan de bestanden: klik op ↻ (vernieuwen) bij de extensie op de chrome://extensions-pagina en herlaad daarna de website.

3Gebruiken

  1. Ga naar een willekeurige website en klik het W-icoon (of Alt+Shift+S). Het paneel verschijnt.
  2. Typ in de opdracht-chat wat je wilt (bv. scrape de prijs, vul veld met {{Naam}}, klik Opslaan, herhaal 5, start), of klik + Stap toevoegen en wijs het element aan.
  3. Optioneel een CSV uploaden → de flow draait één keer per rij (5 regels = 5×).
  4. Start. Met 🔗 Check koppelingen zie je vooraf of elk veld gevonden wordt.

4Zelf bouwen van nul (het idee)

Een extensie is: een manifest dat zegt welke scripts waar draaien. De twee soorten scripts:

SoortDraait waarKan bij
content-script (panel.js)ín de webpaginade DOM (lezen/vullen/klikken) + het paneel tonen
service worker (background.js)op de achtergronddownloads, screenshot, print, tabs, sneltoets

Minimaal manifest.json

// het skelet — meer velden = meer mogelijkheden
{
  "manifest_version": 3,
  "name": "Mijn Scraper",
  "version": "1.0.0",
  "permissions": ["activeTab", "scripting", "storage", "downloads", "tabs"],
  "host_permissions": ["<all_urls>"],
  "background": { "service_worker": "background.js" },
  "content_scripts": [{
    "matches": ["<all_urls>"],
    "js": ["panel.js"],
    "css": ["panel.css"],
    "run_at": "document_idle"
  }],
  "action": { "default_title": "Mijn Scraper" }
}

Kleinste werkende content-script

// panel.js — leest en vult de echte DOM van de pagina
(function(){
  // waarde lezen
  const prijs = document.querySelector("#prijs")?.textContent;

  // veld vullen zoals een gebruiker (events meesturen!)
  function fill(sel, val){
    const el = document.querySelector(sel); if(!el) return;
    el.focus(); el.value = val;
    el.dispatchEvent(new Event("input",{bubbles:true}));
    el.dispatchEvent(new Event("change",{bubbles:true}));
  }
  fill("#naam", "Jan");

  // knop drukken
  document.querySelector("#opslaan")?.click();
})();

Dat is de kiem. De echte panel.js voegt daar het paneel (shadow DOM), het aanwijzen, de CSV-loop, robuuste veld-herkenning (structuur i.p.v. vluchtige id's), datum/dropdown-afhandeling en export aan toe — zie FLOW.md voor de volledige werking.

Kleinste service worker

// background.js — reageert op de toolbar-klik
chrome.action.onClicked.addListener(async (tab) => {
  // bv. een berichtje naar het content-script sturen
  chrome.tabs.sendMessage(tab.id, { type: "toggle" });
});
Belangrijk bij het invullen van frameworks: React/Blazor-velden reageren niet op alleen el.value = .... Stuur input/change-events mee, en bij een gemaskeerd veld (bv. datum dd-MM-yyyy) tik je teken voor teken met document.execCommand("insertText", false, teken) — anders verhaspelt het masker de waarde.

5Optioneel: AI-agent (MCP)

Wil je de tool door een AI laten aansturen (“haal de velden op → hier zijn 30 records → voer ze in”), dan zit er een MCP-server in mcp-server/. Zie mcp-server/README.md: npm install, koppelen aan Claude, en de knop MCP-koppeling in het paneel aanzetten. Draait op localhost, gebruikt je bestaande login.

Publiceren (optioneel)

Zo kunnen anderen hem in één klik installeren:

  1. Zip de inhoud van extension/ (niet de map zelf).
  2. Upload in de Chrome Web Store Developer Dashboard (eenmalig $5), vul de vermelding in en dien in.

WebTool Scraper — lokaal en veilig. Data verlaat je browser alleen als je zelf een webhook of de MCP-bridge (localhost) aanzet. Volledige werking: FLOW.md.
